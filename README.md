# EDS Repository Switch Demo

Source code repository: xiaoyu214/eds-repo-switch-source.

The test content is one homepage in demo-content/index.html. It contains a heading and two paragraphs. scripts/scripts.js adds the observable code marker source-v1. Header and footer blocks are not loaded for this minimal demo.

The content source will remain on this source repository while the EDS site switches its code source to the target account.

AEM Code Sync, site initialization and EDS URL validation are pending task 3. No Admin API credentials or CTO configuration snapshots are stored in this repository.

Based on https://github.com/adobe/aem-boilerplate (Apache-2.0). No additional dependencies installed. The inherited CI workflow is manual only.
